SoNiC_0TAB0

Firefox, Chrome, Opera, Edge… dans une seule fenêtre, en onglets. Groupes colorés, affichage côte à côte, sessions, et une sortie Internet différente par onglet.

⬇ Télécharger pour Windows 🦊 Extension Firefox

Windows 10 / 11 · gratuit · version 1.5 · ~4 Mo

Ce que ça fait

Onglets multi-navigateurs

De vraies fenêtres de Firefox, Chrome, Opera, Edge, Brave… réunies dans une barre d'onglets unique.

Groupes par glissement

Glissez un onglet sur un autre pour les grouper ; couleur et nom personnalisables. Lâchez-le hors de la barre pour le détacher.

Côte à côte

Jusqu'à 4 onglets de navigateurs différents affichés en même temps : colonnes, lignes, grille 2 × 2 ou un grand + les autres.

Sessions

Sauvegarde automatique, restauration de la dernière session ou d'une session nommée.

Une IP par onglet

Chaque navigateur peut sortir par sa propre connexion (box, 4G du téléphone, VPN) avec détection des doublons et des fuites.

Raccourcis

Ctrl+1 … 9 pour changer d'onglet, Ctrl+Tab, et Ctrl+Alt+G pour capturer une fenêtre.

Installer en 3 étapes

  1. Téléchargez SoNiC_0TAB0.zip, puis clic droit → Extraire tout… (ne lancez rien depuis l'intérieur du zip).
  2. Double-cliquez INSTALLER.cmd. Python est détecté et proposé à l'installation si besoin. Choisissez le démarrage avec Windows (normal ou administrateur).
  3. Ouvrez SoNiC_0TAB0, cliquez ＋ pour capturer un navigateur ouvert ou en lancer un nouveau.

Sans installer : SoNiC_0TAB0.cmd. Windows SmartScreen peut afficher un avertissement : le programme n'est pas signé numériquement (« Informations complémentaires » → « Exécuter quand même »). Le code source est lisible dans le zip.

Deux connexions, deux adresses IP

Une carte Wi-Fi ne rejoint qu'un seul réseau à la fois. Pour une seconde sortie Internet, il faut une seconde carte : branchez votre téléphone en USB et activez Paramètres → Connexions → Point d'accès mobile et modem → Modem USB. Dans SoNiC_0TAB0 : ☰ → Réseau → Mes connexions Internet → Détecter → Créer les routes.

Chaque route est une adresse locale du type socks5://127.0.0.1:10810 à choisir dans la liste « proxy » d'un navigateur. L'extension Firefox permet la même chose par conteneur, seule ou avec l'application.

L'extension Firefox

Elle fonctionne sans l'application, en français et en anglais : routes SOCKS5/HTTP (avec identifiants), Tor, sessions restaurées avec conteneurs et routes, test d'IP par conteneur, alerte si deux conteneurs partagent la même IP, import/export. Si l'application est lancée, ses routes s'ajoutent automatiquement.

Firefox n'installe durablement que des extensions signées : essai temporaire via about:debugging → « Ce Firefox » → « Charger un module complémentaire temporaire » (sélectionnez manifest.json du zip extrait), ou signature gratuite par Mozilla (voir PUBLIER.md dans le zip).

À savoir

Fonctionne sur Windows uniquement. Certaines fenêtres refusent d'être intégrées (applications lancées en administrateur alors que SoNiC_0TAB0 ne l'est pas, ou fenêtres protégées) : un message précise la cause.
